# sENG methodology recheck — 2026-09-17

This is a focused second pass over the learning model after the first device test. The goal is not to add fashionable mechanics; it is to change the product only where newer evidence or implementation review gives a concrete reason.

## Conclusion

The core model remains valid:

> Understand it → Retrieve it → Use it → Meet it again → Make it automatic.

No evidence found in this recheck justifies replacing retrieval practice, adaptive spacing, comprehensible input, productive use, extensive reading, targeted corrective feedback, or task-based AI.

## One methodology addition worth making

### Spaced task repetition for speaking and writing

Recent 2025 meta-analyses of task repetition report meaningful benefits for L2 production. Oral task repetition showed particularly clear gains in syntactic complexity and accuracy, with smaller positive gains in fluency and lexical complexity. A parallel meta-analysis of written task repetition found that repetition count, spacing and feedback can moderate outcomes, with feedback especially useful for accuracy.

Product consequence for sENG:

1. A speaking/writing task should not always disappear forever after one completion.
2. High-value tasks can return later with the same communicative goal but slightly changed content.
3. The learner should first attempt the task, receive selective feedback, and then repeat it later rather than immediately memorizing a corrected script.
4. Exact repetition is useful selectively, especially for fluency/accuracy practice, but should not replace varied transfer tasks.
5. Task repetition events must be tracked separately from lexical FSRS reviews; speaking performance is not a flashcard.

Sources:
- Task repetition and L2 oral performance: A meta-analysis (System, 2025): https://www.sciencedirect.com/science/article/pii/S0346251X25002787
- Task repetition and L2 written performance: A meta-analysis (2025): https://www.sciencedirect.com/science/article/pii/S1060374325000803

## Confirmed decisions

### Keep adaptive spacing

The established L2 spacing meta-analysis found a medium-to-large overall effect of spaced practice, with longer spacing producing better delayed outcomes than shorter spacing in the relevant comparisons.

Product consequence: retain FSRS for discrete retrievable items and do not return to fixed 1/3/7-day intervals.

Source: https://onlinelibrary.wiley.com/doi/10.1111/lang.12479

### Keep extensive reading as a core future mode

A 2025 meta-analysis of 73 studies / 82 interventions reported positive effects across reading comprehension, vocabulary, decoding/fluency, motivation, writing, oral proficiency and general proficiency, generally small to medium.

Product consequence: reading must become a real sustained mode, not a set of paragraph-sized quizzes. Include sensible text selection and light accountability without interrupting every paragraph.

Source: https://link.springer.com/article/10.1007/s10648-025-10068-6

### Keep AI task-based, not open-ended by default

A 2025/2026 systematic review and meta-analysis of GenAI in task-based language learning found positive effects and identified instructional moderators such as AI literacy, task planning and task assessor.

Product consequence: AI activities require a target, level, task, planning phase and correction policy. A generic chatbot screen is not the teaching model.

Source: https://link.springer.com/article/10.1007/s11528-025-01140-7

### Do not add media just because media is available

Recent multimedia-vocabulary meta-analysis does not support the simplistic rule that every word should always have text + translation + picture + sound + animation simultaneously.

Product consequence: each modality must contribute information; avoid cognitive clutter.

Source: https://www.sciencedirect.com/science/article/pii/S1747938X25000181

## Implementation issue found during this recheck

Manual module practice previously selected every item of a category, including already-studied items that were not due. Rating those items would reschedule them in FSRS early and contaminate the intended memory schedule.

Fix:
- scheduled module sessions use due items first;
- then unseen items;
- already-studied, not-due items are excluded from scheduler-affecting sessions;
- a future free-practice mode may include them, but its attempts must not silently rewrite the FSRS schedule.

This distinction is important: **extra practice and scheduled memory review are not the same event**.

## Do not change yet

This recheck does not justify:
- forcing typed input on every mobile card;
- adding a leaderboard;
- adding XP as the main progress measure;
- replacing English captions with permanent bilingual subtitles;
- turning pronunciation into a single accent score;
- increasing desired FSRS retention merely to create more reviews;
- generating every learning item with AI in real time;
- showing precise CEFR skill percentages before skill-specific evidence exists.
